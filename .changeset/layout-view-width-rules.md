The router runs against real board rules. A rules island (`build/<board>_rules.json`: min trace width, min clearance, copper-to-edge clearance, per-class width/via defaults) reaches the page when generate runs with `--rules`, and width stepping refuses to go below the floor — the readout warns. The live route carries a gray keep-out halo, the DRC clearance envelope around every drawn piece, that tints red on violation (via rings included, resized in lockstep), and copper samples inside it owe the copper-to-edge clearance to the nearest board edge. Widths come from where you'd expect: each net remembers the last width and via used, W opens the width control, `[`/`]` step the trace width (Alt for fine) and `{`/`}` the via — a via sized by explicit choice is decoupled from the trace width; otherwise the barrel tracks it, floors respected. Net-class defaults from the rules outrank the copper heuristics (regex pattern → class), I eyedrops an existing trace's width, P sizes a power net by current (IPC-2221, the same constants as the library's powerInfo sizer, ΔT 10 °C target, per-layer copper weight from the stackup), and Z solves a controlled-impedance width (Hammerstad microstrip ported verbatim from pcb_impedance.ts, clamped at a 3 mm cap). `?` toggles a legend.
