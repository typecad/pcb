The board viewer gains a sixth view — **Layout** — a KiCad-editor-style arrangement surface over the real gerber stack: zones subdue to blueprint-faint, and every component renders as a draggable outline box (position from its pad centroid, orientation from the pad layout, body size from the footprint name — all derived from the gerbers, so it works in plain browser tabs). Dragging a component snaps to 0.5 mm (arrow keys nudge, Alt for 0.1 mm) and **rips up** its connected copper — every trace, via and pour edge on its nets, plus its pads — greying them until a rebuild lands. Trace provenance comes from a new `build/<board>_routes.json` the board writer emits (`manual` = TrackBuilder-built, `auto` = autorouter, `mixed`): TrackBuilder traces render dashed, autorouted ones solid, with legend chips. "apply & rebuild" hands the move deltas to the VS Code host (disabled in plain browser tabs), which rewrites each component's `<var>.pcb = { x, y }` literal in the board source and rebuilds the project and viewer — computed placements are skipped and reported, never mangled. Rotation editing and TrackBuilder endpoint translation land with phase 2.
