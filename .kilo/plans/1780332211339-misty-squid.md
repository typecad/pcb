# Plan: Document Component Fab/Silkscreen Text Positioning APIs

## Summary
New `referenceLayout`, `valueLayout`, and `fabLayout` properties were added to the `Component` class, along with the `ITextPositioning` interface. These need to be documented on the website.

## New API Surface to Document

### `ITextPositioning` Interface
Shared interface used by all layout options:
- `x`, `y` (required) — position in mm
- `rotation?` — rotation in degrees
- `layer?` — KiCad layer name
- `width?`, `height?` — font dimensions
- `fontSize?` — font size
- `thickness?` — text thickness
- `bold?`, `italic?` — font style
- `justify?` — `{ horizontal?: 'left'|'right'|'center', vertical?: 'top'|'bottom'|'middle', mirror?: boolean }`
- `show?` — visibility toggle

### Component Options (in `ComponentInit`)
- **`referenceLayout`** (`ITextPositioning`) — controls reference designator text on F.SilkS layer
- **`valueLayout`** (`ITextPositioning`) — controls value text on F.Fab layer
- **`fabLayout`** (`ITextPositioning & { text?: string }`) — controls fabrication layer text on F.Fab, defaults text to `${REFERENCE}`
- **`fab`** (`TextPositioning | TextWithPositioning`) — lower-level fab text entry
- **`text`** (`TextEntry[]`) — arbitrary text entries

All three layout properties can be set at construction or assigned after creation.
