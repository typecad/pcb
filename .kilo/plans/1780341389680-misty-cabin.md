### Note on Version Difference
The typecode website uses v0.0.6 while typeCAD uses v0.0.3. The main difference is:
- v0.0.3 uses `this.dataset.code` (accesses source via data attribute)
- v0.0.6 uses `this.parentElement.innerText` (accesses text from parent)

Both work. The v0.0.3 `dataset.code` approach is actually more reliable as it gets the raw source code rather than the rendered text. No version upgrade is needed.
