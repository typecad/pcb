# Plan: Implement Option D — Hybrid Layout Capture for kicad2typecad Roundtrip

## Summary

Change the kicad2typecad `--apply` roundtrip so that layout changes (referenceLayout, valueLayout, fabLayout) are **only generated when the user already has a layout assignment in their source code**. Add a `--capture-layouts` CLI flag to opt into the current behavior (capturing all text positions). Display mode remains unchanged.

## Problem

When the source has no layout assignment, `computeLayoutDiff()` falls back to `(0, 0)` as the "old" position. Since KiCad templates never place text at `(0, 0)`, every component always produces a layout diff, inserting ~3 boilerplate lines per component even when the user never touched text in KiCad.

## Files to Change

### 1. `src/kicad2typecad/types.ts`
- No changes needed. The existing types are sufficient.

### 2. `src/kicad2typecad/rewriter.ts`
- **`computeLayoutChanges(matchResults, captureLayouts?)`**: Add optional `captureLayouts` parameter (default `false`). When `sourceLayout === null` and `captureLayouts` is `false`, skip the layout type (do not generate a `PendingLayoutChange`). When `captureLayouts` is `true`, keep current behavior.
- **`applyLayoutChanges(changes)`**: No changes needed — this method already handles both existing and new layout assignments. The filtering happens upstream in `computeLayoutChanges`.
- The "insert new layout line" branch (lines 256-275) will still work correctly — it just won't be reached for new layouts unless `captureLayouts` was `true`.

- When `captureLayouts` is `false` and layout changes come back empty, show a message like: `"Layout positions use template defaults (no layout assignments in source). Use --capture-layouts to import all text positions."`

async computeLayoutChanges(
    matchResults: MatchResult[],
    captureLayouts = false
): Promise<PendingLayoutChange[]> {
    // ... existing logic ...
    
    for (const layoutType of layoutTypes) {
        const irLayout: TextLayoutIR | undefined = fp[layoutType];
        if (!irLayout) continue;

        const sourceLayout = this.getSourceLayout(...);

        // NEW: Skip if source has no layout and captureLayouts is false
        if (sourceLayout === null && !captureLayouts) continue;

        const diff = this.computeLayoutDiff(sourceLayout, irLayout);
        if (diff.length === 0) continue;
        // ... rest unchanged ...
    }
}

### cli.ts changes

```ts
// Options type:
options?: { apply?: boolean; captureLayouts?: boolean }

// In applyMode:
const layoutChanges = await rewriter.computeLayoutChanges(
    matchResults,
    options?.captureLayouts ?? false
);

// After layout section, when no changes and captureLayouts is false:
if (layoutChanges.length === 0 && !options?.captureLayouts) {
    const hasLayoutsInIR = matchResults.some(mr =>
        mr.irFootprint.referenceLayout || mr.irFootprint.valueLayout || mr.irFootprint.fabLayout
    );
    if (hasLayoutsInIR) {
        logger.log(chalk.gray(
            '\nLayout positions use footprint template defaults. ' +
            'Use --capture-layouts to import all text positions into source.'
        ));
    }
}
```
