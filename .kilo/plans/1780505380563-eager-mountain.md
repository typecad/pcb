# Plan: Add `typecad package` command

## Overview
Add a new `package` command to the typeCAD CLI that searches npm for packages with the keyword `typecad-package`, presents them in a multi-select list, and installs the selected ones. Uses the already-installed `@inquirer/checkbox` (re-exported from `@inquirer/prompts`) for the selection UI.

## Files to Create

### 1. `src/cli/typecad/commands/package.ts` (new file)
The command handler. Responsibilities:
- **Fetch** from `https://registry.npmjs.org/-/v1/search?text=keywords:typecad-package&size=250` using Node's built-in `fetch` (no new deps)
- **Read** the local `package.json` (walking up from cwd) to determine already-installed packages and their versions
- **Parse** the npm search response (`objects[].package`) to extract `name`, `version`, `description`
- **Build choices** for `@inquirer/prompts` checkbox:
  - Not installed: normal display — `name - description (version)`
  - Installed, same version: disabled, grayed out — `name - description (installed)`
  - Installed, different version: selectable, styled — `name - description (installed v1.0.0, latest v2.0.0 → update)`
- **Run** `npm install <selected-packages>` via `execFileSync` using the same `runSync` pattern from `create_project.ts` (handles Windows `.cmd` shim issue via `findExecutable`)
- Styling: match existing convention — `chalk.white.bold('typecad package')` header, `chalk.green('+')` for success messages, `chalk.gray` for installed items

## Behavior Details

### Already-installed detection
- Walk up from cwd to find the nearest `package.json`
- Check `dependencies`, `devDependencies`, and `optionalDependencies` for matches
- Compare installed version with latest from npm registry

### Checkbox display
Using `@inquirer/prompts` checkbox (already available via `@inquirer/checkbox`):
- Each choice: `{ value: packageName, name: displayString, disabled?: boolean | string }`
- Disabled items (already installed, same version) use `disabled: 'already installed'`
- Different version items remain selectable with a note about the version difference

### Installation
- Selected packages are installed via `npm install` using `execFileSync` with the `findExecutable` pattern from `create_project.ts`
- Install runs from the directory containing the project's `package.json`

## No New Dependencies
- Uses Node.js built-in `fetch` (available since Node 18, which is the minimum required version per `package.json` engines)
- Uses `@inquirer/prompts` (already a dependency) for checkbox UI
- Uses `chalk` (already a dependency) for styling
- Uses `findExecutable` from `src/kicad.js` for cross-platform npm execution
