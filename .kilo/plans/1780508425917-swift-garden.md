## Behavior

```
typecad export gerbers
# -> finds ./build/*.kicad_pcb, exports to ./build/gerbers/

typecad export gerbers --output ./fab
# -> exports to ./fab/

typecad export gerbers ./myboard.kicad_pcb
# -> exports specified PCB

typecad export gerbers -- --exclude-drawing-sheet --use-drill-file-origin
# -> passes extra flags to kicad-cli
```

## Implementation Details

- The command runs two kicad-cli invocations sequentially:
  1. `pcb export gerbers --output <dir> [passthrough] <pcb>`
  2. `pcb export drill --output <dir> [passthrough] <pcb>`
- Both use `stdio: 'inherit'` so kicad-cli output is visible
- The `--output` / `-o` flag is consumed by the typecad command (not passed through), while everything after `--` goes to kicad-cli
- JSON output mode reports: `{ pcb, gerberDir, gerberFiles: [...], drillFiles: [...] }` (lists generated files)
