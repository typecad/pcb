# Plan: Convert @typecad/jlcpcb-export to CLI Tool

## Goal
Convert `@typecad/jlcpcb-export` from a library that must be imported as source code into a standalone CLI binary (like `@typecad/typecad` has `typecad` CLI). This eliminates the need for users to write TypeScript code that imports and calls `jlcpcb_export()` — instead they run `npx jlcpcb-export <board-name>`.

## Key Insight: Remove @typecad/typecad Dependency
The current library requires `Schematic` and `PCB` runtime objects, but they're only used for:
- `pcb.boardName` → CLI arg
- `schematic.error()` / `schematic.warn()` → console.error / chalk
- `schematic.bom()` → copy existing BOM CSV from build dir (typecad's `PCB.create()` already generates it)
- `KiCAD.cliPath` → use `kicad-cli` on PATH (or `--kicad-cli` flag)

The CLI tool can operate directly on `.kicad_pcb` files and the existing BOM CSV without needing the typecad runtime.

## File Changes

### 1. DELETE `index.ts` (root-level, replaced by `src/index.ts`)

### 2. NEW `src/index.ts` — CLI entry point
- Shebang: `#!/usr/bin/env node`
- Parse CLI args (simple, hand-rolled like typecad's pattern):
  - `board-name` (required positional arg) — the board name (matches .kicad_pcb filename prefix)
  - `--ignore` / `-i` — ignore DRC failures and dirty git repo
  - `--input <path>` — input build directory (default: `./build`)
  - `--output <path>` — override output directory (default: `./build/jlcpcb-{version}`)
  - `--kicad-cli <path>` — path to kicad-cli binary (default: `kicad-cli`)
  - `--version` / `-v` — print version
  - `--help` / `-h` — print help
- Read version from user's `package.json` (found by walking up from CWD)
- Logic flow (same as current, but standalone):
  1. Create output directory
  2. Run DRC on `{input}/{boardName}.kicad_pcb`
  3. Check git status
  4. Generate position file, replace headers (Ref→Designator, PosX→Mid X, etc.)
  5. Generate gerbers
  6. Generate drill file
  7. Zip gerbers + drill
  8. Copy BOM from `{input}/{boardName}.csv` to output dir, replace MPN→JLCPCB Part#
  9. Print completion message with JLCPCB URL
- Error handling: exit with code 1 on failure (unless `--ignore`)
- Import style: use `.js` extensions for NodeNext ESM compatibility
