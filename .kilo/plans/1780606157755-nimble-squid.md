# Plan: Convert async functions to sync in @typecad/typecad

## Goal
Make `PCB.create()` and the entire core library API synchronous by eliminating unnecessary async/await patterns. The root cause is dynamic `import()` calls for `acorn`/`acorn-walk`, which can be replaced with static imports since they're already hard dependencies.

## Scope

### In scope (core library + supporting infrastructure)
- `PCB.create()` chain: `PCB.create` → `createBoard` → `awaitPendingInspections` → `inspectSource` → `loadAcorn`
- Autoroute chain: `PCB.route()` → `pcbRoute` → `pcbAutoroute` → `autoroute` (already sync)
- `kicad2typecad` source analysis: `analyzeFile` → `parseSourceAsync` → `loadAcorn`
- `kicad2typecad` rewriter/matcher: all methods that delegate to `analyzeFile`
- `kicad.ts` `hasLocalSymbols()`: uses `node:fs/promises` readdir

### Out of scope (inherently async - CLI commands)
- CLI entry points (`src/cli/typecad/index.ts` and all `commands/*.ts`) — use inquirer, fetch, child_process
- `kicad-symbols` subsystem — file I/O, data management, search CLI
- `kicad_commands.ts` `executeKiCADCommand()` — spawns child processes (used only by CLI)
- `gitdiff` utilities — child process execution for KiCad CLI
- `docgen` — file generation pipeline
- Worker thread pool (`routing/router/worker_pool.ts`, `segment_worker.ts`) — inherently async

## Phase 1: Static imports for acorn in `source_inspector.ts`

**File**: `src/utils/source_inspector.ts`

1. Replace dynamic imports with static imports at top of file:
   ```ts
   import * as acorn from 'acorn';
   import { simple as walkSimple } from 'acorn-walk';
   ```
2. Remove the `_acorn`/`_walk` module-level cache variables and the `loadAcorn()` function
3. Make `inspectSource()` synchronous — remove `async`, change return type from `Promise<{...}>` to `{...}`
4. Update all internal references from `_acorn!.parse(...)` to `acorn.parse(...)` and from `_walk!` to the walk imports

## Phase 2: Make component inspection synchronous

**File**: `src/component.ts`

1. Remove the `pendingInspections` Set and the `awaitPendingInspections()` export function
2. Make `captureSourceInfo()` synchronous — call `inspectSource()` directly (no longer returns a Promise):
   ```ts
   private captureSourceInfo(): void {
       const callSite = this.getCallSiteForInstantiation();
       if (callSite) {
           this.sourceInfo = { file: callSite.file, line: callSite.line, variable: undefined, params: undefined, isThis: undefined };
           try {
               const inspection = inspectSource(callSite.file, callSite.line);
               if (inspection.variable) {
                   this.sourceInfo.variable = inspection.variable;
                   this.sourceInfo.params = inspection.params;
                   this.sourceInfo.isThis = inspection.isThis;
               }
           } catch (e) {
               logger.debug('Source inspection failed:', String(e));
           }
       }
   }
   ```

## Risk Assessment

- **Low risk**: Static acorn imports (already hard dependencies in package.json)
- **Low risk**: Removing pendingInspections mechanism (source inspection is now sync, happens at construction time)
- **Low risk**: Making autoroute sync (it was already sync, just wrapped in Promise.resolve)
- **Medium risk**: Test updates — many tests will need `async`/`await` removed; careful not to break test assertions
- **Medium risk**: `kicad2typecad/cli.ts` interactive functions — these mix sync computation with async inquirer prompts; needs careful handling
