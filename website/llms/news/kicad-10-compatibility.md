# KiCad 10 Compatibility

KiCad 10 is currently in release candidate, and we're actively testing typeCAD to ensure full compatibility ahead of the final release.

## Current Status

We're in the process of updating and verifying that typeCAD works correctly with KiCad 10. So far, the main `@typecad/pcb` package is working well with the new release.

## What's Next

We'll continue testing the rest of the typeCAD ecosystem, including:

- Package generation tools
- CLI utilities
- MCP server integration

If you encounter any issues using typeCAD with KiCad 10, please report them on our [GitHub issues](https://github.com/attypecad/typecad/issues).
