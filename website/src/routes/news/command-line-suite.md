# A suite of command-line tools
We've just released [typecad-docgen](https://www.npmjs.com/package/@typecad/pcb-docgen) to automate the generation of KiCAD documentation from markdown files. This works nicely with the other command-line tools we've released.
- [wiring](https://www.npmjs.com/package/@typecad/wiring) - Programmatically create wiring diagrams
- [typecad-gitdiff](https://www.npmjs.com/package/@typecad/pcb-gitdiff) - See the differences between KiCAD PCB files  

Using those tools along with typeCAD means a huge portion of the workflow can be automated and also easily integrated into your CI/CD pipeline.
